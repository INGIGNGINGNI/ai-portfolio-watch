คำถามที่พบบ่อยเกี่ยวกับคอร์ส AI เฝ้าพอร์ต

n8n คืออะไร และใช้ทำอะไรในคอร์สนี้? keyboard_arrow_down

n8n เป็นเครื่องมือสร้างระบบทำงานอัตโนมัติ (Workflow Automation) ที่ต่อบริการต่างๆ เข้าหากันเป็นขั้นตอน ใช้ได้ทั้งแบบ Cloud และติดตั้งบน Server ของตัวเอง ในคอร์สนี้ใช้ n8n ดึงข้อมูลตลาด เทียบกับกติกาที่คุณตั้ง แล้วส่งสรุปเข้า Telegram

NVDR คืออะไร ทำไมใช้ติดตามเงินต่างชาติ? keyboard_arrow_down

NVDR (Non-Voting Depositary Receipt) คือตราสารที่ออกโดยบริษัท ไทยเอ็นวีดีอาร์ จำกัด บริษัทย่อยของตลาดหลักทรัพย์แห่งประเทศไทย ผู้ถือได้สิทธิประโยชน์ทางการเงินเหมือนถือหุ้นแต่ไม่มีสิทธิออกเสียง นักลงทุนต่างชาติจำนวนมากซื้อขายผ่าน NVDR ข้อมูลซื้อขาย NVDR รายหุ้นจึงใช้เป็นข้อมูลประกอบการติดตามกระแสเงินต่างชาติได้ แต่ไม่ใช่สัญญาณซื้อขาย

พอร์ตแบบ All Weather คืออะไร? keyboard_arrow_down

แนวคิดจัดพอร์ตกระจายไปหลายสินทรัพย์ เช่น หุ้น ตราสารหนี้ และทอง ให้รับมือได้ทั้งช่วงเศรษฐกิจโต ชะลอ เงินเฟ้อ และเงินฝืด แนวคิดนี้เป็นที่รู้จักจาก Ray Dalio และ Bridgewater Associates ในคอร์สนี้ระบบจะเทียบสัดส่วนพอร์ตจริงกับแผนที่คุณตั้งทุกสัปดาห์ และแจ้งเมื่อเบี่ยงเกินกรอบ

ไม่เคยเขียนโค้ดเลย เรียนได้ไหม? keyboard_arrow_down

ได้ คอร์สออกแบบให้ใช้ Template และให้ AI ช่วยเขียนส่วนที่เป็นโค้ด คุณแค่อธิบายกติกาเป็นภาษาคน และมีผู้ช่วยสอนในห้อง

บอทจะซื้อขายแทนฉันไหม? keyboard_arrow_down

ไม่ บอทส่งข้อมูลและแจ้งเตือนตามกติกาของคุณ ส่วนการส่งคำสั่งต้องให้คุณกดยืนยันทุกครั้ง คุณเป็นผู้ตัดสินใจเสมอ

หลังเรียนจบมีค่าใช้จ่ายอะไรบ้าง? keyboard_arrow_down

ขึ้นกับทางที่เลือก เช่น ค่า n8n Cloud หรือค่าเช่า Server ค่าบริการ AI ตามการใช้งาน และค่าข้อมูลตลาด ในคอร์สจะสอนวิธีเลือกให้คุ้มกับขนาดพอร์ต และมีทางเลือกแหล่งข้อมูลอื่นสำหรับเริ่มต้น

ต้องมีบัญชี Settrade Open API ไหม? keyboard_arrow_down

ไม่บังคับ ใช้เฉพาะส่วน Real-time และส่งคำสั่ง ถ้ายังไม่มี ยังทำระบบส่วนอื่นได้ครบ และได้คู่มือไปต่อเองภายหลัง

ดูย้อนหลังได้ไหม? keyboard_arrow_down

ได้ ผู้เรียนดูวิดีโอย้อนหลังได้นาน 1 ปี ผ่านหน้าเรียนบน efin.finance โดยวิดีโอจะเปิดให้ดูหลังจบคอร์ส 5 วันทำการ และเราจะแจ้งทางอีเมลเมื่อวิดีโอพร้อม

ถ้าติดตรงไหนหลังเรียนจะทำอย่างไร? keyboard_arrow_down

ถามในกลุ่มถาม-ตอบ หรือจองคิว Hot Seat ใน Fix-it Clinic ภายใน 30 วันหลังเรียน

เนื้อหาเป็นคำแนะนำการลงทุนไหม? keyboard_arrow_down

ไม่ใช่ คอร์สสอนการสร้างเครื่องมือติดตามตามกติกาที่คุณกำหนดเอง ไม่แนะนำซื้อขายหุ้นรายตัว
